# recipe: 관리 콘솔 화면

## 언제 쓴다
HiNAS 365 내부 관리 화면 전부 — 리스트·상세·대시보드·설정 등,
"로그인한 운영자가 좌측 메뉴로 오가며 쓰는 화면"이면 기본값으로 이 레시피다.

## 구성
- **앱 셸 필수**: 좌측 사이드바 내비(그룹 라벨·아이콘, `Sidebar` collapsible="none")
  + 상단바(브레드크럼 좌측, 우측에 시계·알림·아바타).
- 콘텐츠는 셸 안에서 **전폭**(`SidebarInset` + `p-8`), 페이지 제목 `text-2xl font-bold`
  + 우측 주요 액션 버튼(페이지당 primary 1개).
- 리스트 화면: 검색(`InputGroup`)+필터 툴바 → `Table`(2줄 링크 셀·칩·상태 도트) → `Pagination`.
- 상세 화면: 브레드크럼에 개체명 추가, kv 카드(`Item` 조합)·아코디언·탭 조합.
- 사이드바 메뉴 구성을 모르면 **묻지 말고 원본 제품 구조(운영/호선 관리/업데이트/관리)를 기본값**으로 쓴다.

## 언제 안 쓴다
- 인증·랜딩·문서형 페이지 (셸 없음, 중앙 정렬 카드 또는 프로즈 폭)
- 독립 실행 위저드 → `wizard.md`
- 외부 공유용 단독 뷰(리포트 출력 등)
