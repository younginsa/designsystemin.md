# recipes/ — 페이지 유형 레시피

**강제 규칙이 아니라 이름 붙은 선례다.** 생성 세션은 요청을 이 폴더의 레시피와
**대조**하고, 맞으면 어떤 레시피로 가는지 선언한 뒤 그 관례를 상속한다.
맞는 게 없거나 애매하면 — 억지로 끼워맞추지 말고 **생성 전에 질문한다** (CLAUDE.md 계약).

## 등재 규칙

- 모든 레시피는 **"언제 안 쓴다"를 반드시 포함**한다.
- 사용자는 채팅에서 언제든 오버라이드할 수 있다 ("셸 빼줘" 한 마디면 됨).
- 추가·수정은 커밋으로만 = 저장소 관리자(디자이너) 승인 게이트를 지난다.
- 새 유형은 ask-first를 거쳐 잘 만들어진 뒤, 관리자가 지시할 때 레시피로 등재한다.
