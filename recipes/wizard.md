# recipe: 위저드 (다단계 입력)

## 언제 쓴다
3단계 이상 순차 입력 흐름 — 계약 등록, 호선 생성, 업데이트 진행 등.

## 구성
- 상단에 **스테퍼**(`Stepper` — 완료 체크·현재 강조·미래 muted)로 전체 단계 표시.
- 모달형(호선 생성)과 전면형(계약 등록·업데이트) 둘 다 가능 —
  전면형이면 `admin-console.md`의 앱 셸 **안에** 놓인다 (셸 생략 금지).
- 본문은 단계당 하나의 폼 영역: 섹션 라벨(작은 대문자 muted) + `Field` 그리드.
- 하단 고정 바: 좌측 이탈 경고·안내 문구(muted), 우측 [이전](outline)·[다음/검증하고 계속](primary).
- 마지막 단계는 검토 요약(입력 값 kv 나열 + 단계별 수정 링크).
- 위저드 상태는 커밋 전 저장되지 않음을 하단에 명시한다.

## 언제 안 쓴다
- 1~2단계 입력 → 일반 폼 페이지 또는 `Dialog`
- 조회·필터 중심 화면 → `admin-console.md`
