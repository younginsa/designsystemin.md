계기
프론트가 스톡 shadcn 위에 DS를 수작업 CSS 4파일(primitives · semantic-token · typography · index)로 이식 중임을 확인(Slack). 검토에서 값 오타 3건(gray-200 · olive-900 · cyber-security 참조 오류), 폰트 불일치(코드 Noto Sans ↔ 피그마 Inter), 라이트 단일 모드 한계 발견 — 수작업 동기화를 끝낼 정본이 필요했다.
CSS 핸드오프 개통
ds:build가 프론트 파일 구조 그대로의 정본 4파일 + zip을 자동 생성, 배포 URL(/dstk/handoff/)로 push마다 상시 최신. 참조 사슬 구조 — 값은 primitives 단독 소유 → 시맨틱은 var() 참조(교차 조명 핀은 --dusk-red-600 패턴 프리픽스, Control 블록은 전량 프리픽스) → shadcn 매핑. 시맨틱이 부르는 변수의 실재를 빌드 자기검사로 전수 대조(실패 = 빌드 중단). 다운로드 버튼은 04 사용법.
Desktop 타이포 첫 코드화
피그마 Desktop 텍스트 스타일 10종(Inter) 실측을 dstk/typography.json에 편입 — 종전 dstk는 시거리(2m/3m) 스케일만 보유했다. shadcn text-* 축 확정: sm=13/20(body) · base=14/20(title-xs) — 수치는 타이포 변수가 단독 소유, 축은 매핑만.
