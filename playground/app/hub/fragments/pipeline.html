파이프라인 — 스크린샷에서 DS, DS에서 페이지까지

1 업로드
제품 스크린샷 또는 HTML 파일을 입력으로 올린다.
2 컴포넌트 추출
화면을 판독해 UI 컴포넌트를 추출하고 그룹으로 분류한다 → 365 탭 「컴포넌트 채택」에 카드로 등재.
3 shadcn 매핑
추출된 각 컴포넌트를 shadcn 기본형과 매핑한다. 카드의 기본 상태가 shadcn 렌더, hover가 원본 컷, 칩이 매핑 결과다. 직접 대응이 없으면 shadcn: 없음으로 표기하고 커스텀 제작 대상으로 남긴다.
4 채택 판정
카드에서 컴포넌트별 채택 여부를 토글로 결정한다 — 채택된 것만이 DS 어휘다(유일한 게이트). shadcn 매핑분은 기본형 위에 값 조정·토큰을 얹고, 매핑 없는 것은 원본 재현으로 제작 완료된 뒤 같은 채택 절차를 밟는다. 결과는 approved.json으로 커밋되어 팀과 공유된다.
5 페이지 생성
저장소를 클론한 폴더에서 Claude Code 세션에 바로 채팅하면 된다 — CLAUDE.md 계약이 자동 적용되어, 켤 때마다 최신 DS를 받고 채택 컴포넌트·365 토큰만으로 뼈대 페이지를 만들어 대화로 다듬는다(기본·빈·로딩·에러 4개 상태 포함). 절차는 「사용방법」의 빠른 시작 참고.
6 365 브랜딩 적용 예정
생성된 페이지를 미리보기 패널에서 확인하고 [365 DS 적용]으로 타이포·컬러·라운드 등 365 토큰을 입힌다. [shadcn]/[DS 적용] 탭으로 전환 비교. 선행 조건: 365 토큰 값 정의(상태 색 도입 범위 포함).

토큰 파이프라인

원천
dstk/*.json — W3C DTCG 표준, core → semantic 참조 구조.
산출
pnpm ds:build → CSS 변수(dist/dstk.css) + Tailwind 프리셋 → playground·생성 페이지가 사용. 빌드·커밋은 관리자만.
365 토큰
ds365.json — 채택 카탈로그의 365 토큰·값 조정 기록(현재 1차: 네이비·각짐). 값이 확정되면 dstk로 편입한다.

레퍼런스 구현 스택

레퍼런스 구현 스택: React + Tailwind + shadcn/ui 계열. 화면 이해(시각 스펙)용이며, 토큰 JSON은 중립이므로 다른 스택 제품도 토큰을 가져다 쓸 수 있다.

Theme × dstk 대조표

피그마 「Theme × dstk 대조표」와 같은 데이터 — Theme 변수 ↔ dstk 토큰 매핑. 원천 dstk/figma-theme-snapshot.json, ds:build가 대조 검증 후 게시한다.

HiNAS 365 DS — 공통 DS 위의 제품 층

무엇
공통 DS 위에 채택 어휘(approved.json)와 365 토큰(ds365.json)을 얹은 HiNAS 365 전용 층. 채택된 것만이 어휘다.
관리 위치
채택 토글·현황은 「컴포넌트 채택」, 토큰·값 조정은 「365 DS」, 레이아웃 프레임은 「페이지 템플릿」, 기획 입력 기록은 「히스토리」 — 모두 365 탭.
현재 상태
365 토큰 1차(네이비·각짐) 정의됨 — 상태 색·타이포·간격 정의가 다음 단계(6단계 브랜딩의 선행 조건).

팔레트 — 유일한 색 원천 dstk/palette.json · 피그마 fill 실측

번호는 밝기가 아니라 역할(50=배경 · 100=면 · 900=최대 대비) — 시맨틱이 번호만 참조하면 조명 모드 전환이 자동이다. ★ = 대비 인증 앵커(Day=600 · Dusk·Night=500).

공통 시맨틱 — 이름표 (동결)

값 직접 기입 금지 — 전부 팔레트 참조(빌드 게이트가 강제). 모드별 해석값을 나란히 보인다.
상태-토큰 매핑(상태 이름 ≠ 토큰 이름): WARNING(심각)=destructive · CAUTION(주의)=warning · UNREAD(미확인)=info · NORMAL(정상)=success — 위계 빨강 > 주황 > 파랑 > 초록.

타이포 스케일 — 시거리 기반(1M/2M)

피그마 HiNAS Control DNV TA 실측(4K 캔버스 px). 근거: ISO 8468 6.3.4.1 — 글자 높이(mm) ≥ 3.5 × 시거리(m), 폭 = 0.7 × 높이. 원문·생성 게이트: regulations/control.md
