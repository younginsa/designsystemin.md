# layout: 본문 패턴 — A 리스트 · B 상세 · C 위저드 · D 대시보드 · E 프로그레시브 폼

프레임(①②…)이 화면의 껍데기라면, **본문 패턴은 본문 영역 안의 구성 선례**다.
번호가 아니라 **문자(A B C…)**로 매긴다 — ask-first에서 "① 프레임 + C 본문"처럼
프레임 번호와 섞여도 충돌하지 않는다. 강제 규칙이 아니라 선례이며,
사용자가 준 스크린샷·와이어프레임이 항상 우선한다.

## 공통 규칙 (모든 본문 패턴)

- **본문 컬럼을 벗어나지 않는다** — 고정 요소(하단 바·플로팅 버튼 포함)도
  좌측 경계 = 사이드바 우측 끝. `inset-x-0` 같은 전폭 고정 금지.
- **폼 인풋 폭**: 텍스트 인풋·셀렉트·숫자 인풋은 최대 `max-w-sm`(384px).
  좌우로 나란히 둘 때는 2열 그리드.
- **섹션 리듬** = `space-y-6`(24px) — 전 페이지 공통(피그마 실측 40px에서 조정, 사용자 확정).
- **카드 종류 혼용 금지** — A·B·C 본문의 카드 = 보더 카드(`rounded-lg border bg-card`).
  그림자 카드(`shadow-card`)는 **D 대시보드 전용**.
- **섹션 타이틀·설명 위계** — 카드/섹션 타이틀 = `text-sm font-medium
  text-muted-foreground`(14px 회색), 타이틀 바로 아래 설명 = `text-xs
  text-muted-foreground`(12px). 예외: 문서 본문 대제목(릴리즈 노트 What's Changed류)과
  정보 패널의 `text-xs uppercase` 라벨은 별개 요소.

## A — 리스트 (2026-09-02 개정 — 확정 문법 반영)

구조(위→아래 고정): **타이틀 행 → FilterBar → Table → 푸터**.

- **타이틀 행**: 단일 줄 `items-center` — 좌 타이틀, 우측에 페이지 레벨 CTA.
- **FilterBar 프리셋 전담**: 자동 열림(openName 단일 소유), 목록 액션([내보내기] 등)은
  `actions` 슬롯 — 표 위 임시 배치 금지. 검색은 SearchBox(✕ 클리어).
- **역할 분리**: 필터 = FilterBar 전담 · 헤더 = 정렬 전담(헤더에 칩·셀렉트 금지).
- **Table**: 2줄 링크 셀·칩·상태 도트. 빈 결과 = `Empty`(조건 초기화 버튼).
- **푸터**: 「페이지당: [15˅] │ 전체 N건」 — RowsPerPage 프리셋, Pagination과 같은 행.
  보조 카운트는 괄호 병기 — 예) "전체 247척 (● 미입력 38척)".
- **언제 안 쓴다**: 단일 개체 상세(B), 카드 중심 현황판(D).

## B — 상세

- 브레드크럼에 개체명 추가. 페이지 제목 아래 좌측 요약 패널(kv 카드) + 우측 본문.
- kv 카드(`Item` 조합)·아코디언·탭 조합. 상태 이력은 `Timeline`.

## C — 위저드 (다단계 입력)

- 상단 `Stepper`(완료 체크·현재 강조·미래 muted). 3단계 미만이면 일반 폼 또는 `Dialog`.
- 단계당 하나의 폼 영역: 섹션 라벨 + `Field` 그리드.
- **레이아웃은 필하이트**: 본문 영역이 잔여 높이를 전부 채우고 스크롤을 담당한다.
  **하단 바(이전/다음)는 본문 컬럼 하단에 상시 고정** — 스크롤과 무관하게 항상 보인다.
  좌측 "커밋 전 저장되지 않음" 안내(muted), 우측 [이전](outline) · [다음/검증하고
  계속](primary). 본문 컬럼 안에서만 — 사이드바를 덮지 않는다.
- 마지막 단계는 검토 요약(입력 값 kv 나열 + 단계별 수정 링크).

## D — 대시보드 (카드 캔버스)

값은 전부 dstk 토큰 참조 — 임의 hex·px 금지.

- **표준 조립 (2026-09-02 추가)**: ① KPI/스탯 카드 행 — 카드 3개(`grid-cols-3`) 또는
  4개(`grid-cols-4`), `gap-4` ② 그 아래 타이틀+테이블 카드(전폭, `Table variant="plain"`).
  **"카드 행 + 테이블"이 대시보드의 기본 골격** — 카드 행은 복수 허용, 섹션 리듬 `space-y-6`.
- **언제 안 쓴다**: 목록 탐색이 주 목적(A), 단일 개체(B).

- **캔버스**: 본문 배경 = `bg-secondary`(#F9FAFB — Theme 정렬 후 캔버스 의도값,
  `background`는 White로 카드와 동일), 패딩 `p-8`.
- **카드**: `rounded-lg bg-card shadow-card` — **보더 없음**. 그림자는 `shadow-card`
  토큰(0 0 12px 0, border 토큰색 — 상하 대칭 확산, 모드 자동).
- **간격**: 카드 그리드 `gap-4`, 섹션 리듬 `space-y-6`(공통 규칙과 동일).
- **적용 범위**: 그림자 카드는 대시보드 전용 — 다른 본문(A/B/C)에 가져가지 않는다.
- **카드 형식 ① 타이틀 카드**: 헤더 `px-4 py-3`(밑줄 없음), 타이틀 `text-sm
  font-medium text-muted-foreground` + 우측 정보 아이콘 슬롯.
- **카드 형식 ② 타이틀+테이블 카드**: 같은 헤더 + **`Table variant="plain"`**(경량 표 —
  외곽선·헤더 배경 없음, 행 구분선 마지막 제외, 셀 `px-4 py-3`). 손 unwind 금지 — variant만.
- **스탯 카드**: 항목 `flex-1` 균등, 첫 항목 `pl-4`, 구분 항목 `border-l pl-8`,
  숫자 `text-2xl font-bold`, 라벨 `mt-1 text-sm text-muted-foreground`.

## E — 프로그레시브 폼 (조건 노출 단일 페이지 생성 폼 — 2026-09-02 신설)

계약 생성 화면(5단계 위저드 → 단일 페이지 전환, 2026-09-01 확정)에서 검증된 문법.
**C 위저드와 다르다** — Stepper·단계 이동 없음, 조건 충족 시 하단으로 섹션이 자동 노출.

레이아웃: **가운데 정렬 단일 컬럼** — `mx-auto w-full max-w-4xl space-y-6`.
본문 컬럼 규칙·인풋 폭(max-w-sm)·섹션 타이틀 위계는 공통 규칙 상속.

- **게이트 조건**: 첫 섹션(필수 필드 그룹)이 전부 채워지면 다음 섹션이
  하단에 자동 오픈(+스크롤 이동). 미충족 시 다음 섹션 진입 CTA는 disabled.
- **연쇄 노출**: 섹션 안에서도 선택이 다음 필드를 부른다 —
  예) 제품 타입 선택 → 구성 패널·슬롯 수 노출, 슬롯 배정 → 단가·통화 노출,
  셀렉트 「직접 입력」 → 숫자 인풋 전환. 숨김은 자리 차지 없이 완전 미렌더.
- **선택지 라디오**: 소수 고정 선택지(패키지 5종 등)는 카드형 라디오 그리드
  (`grid-cols-3`, 2행 허용) — 드롭다운으로 뭉개지 않는다.
- **반복 블록**: 항목 N개 반복(계약 항목 등) — [+ 항목 추가]는 게이트 충족 시에만
  활성. 블록 사이 간격은 기본 리듬의 2배(시각 구분).
- **개체 연결 필드**: 기존 개체 검색·연결은 Popover+Command 콤보박스 —
  빈 상태 문구("생성된 호선 없음") + 푸터 [+ 새로 만들기] → 생성 모달
  (`sm:max-w-2xl`, 필드 그룹은 아웃라인 박스 `rounded-md border p-4`로 구획).
- **하단 고정 바**: `sticky bottom-0 bg-secondary py-3` — 캔버스와 같은 배경
  (흰 띠·보더 금지), 좌 [취소] · 우 [등록 완료](primary). 본문 컬럼 안에서만.
- **언제 안 쓴다**: 단계 순서 강제·단계별 검증이 필수면 C 위저드,
  필드가 소수인 단순 입력은 일반 폼 또는 Dialog, 목록·상세는 A/B.

## 등재 규칙

- 새 패턴 추가는 관리자 커밋으로만. 문자 = 이 파일의 목차 순서.
- 365 페이지 「페이지 템플릿」의 본문 패턴 카드도 같은 문자로 함께 추가한다.
