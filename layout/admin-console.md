# layout: ① HiNAS 365 메인 레이아웃

(파일명은 `admin-console.md`를 유지한다 — 표시명·번호는 README 목록 기준.)

## 언제 쓴다
HiNAS 365 내부 화면 전부 — 리스트·상세·대시보드·설정·다단계 입력 등,
"로그인한 운영자가 좌측 메뉴로 오가며 쓰는 화면"이면 기본값으로 이 레이아웃이다.
본문에 무엇이 오는지는 레이아웃과 무관하다 — 사용자가 준 스크린샷·와이어프레임이
본문 내용을 결정한다. ("업로드한 스샷을 메인 레이아웃 본문에 넣어줘"가 표준 요청 문장.)

## 구조 — 2컬럼
**사이드바(좌)가 페이지 최상단~최하단 풀하이트**를 차지하고,
**상단바는 사이드바 우측 끝에서 페이지 우측 끝까지만** 걸친다.
(상단바가 페이지 전폭을 가로지르는 구조가 아니다.)

## 영역 — 요청·수정 지시에서 이 이름으로 부른다
- **사이드바(메뉴)** — 좌측 풀하이트 고정. `Sidebar`(collapsible 접기 지원).
  - **최상단 브랜드 존**: `HiNAS 365` 워드마크 + 앱 그리드(앱 전환) 아이콘.
    환경 배지(LOCAL 등)는 표시하지 않는다.
  - **중앙 메뉴**: 그룹 라벨 + 아이콘 항목. 구성을 모르면 묻지 말고
    원본 제품 구조(운영/호선 관리/업데이트/관리)를 기본값으로 쓴다.
  - **하단 고정 존**: 사용자 계정(아바타+이름) → **구분선** → 접기 토글(아이콘 +
    "메뉴 접기" 레이블). 구분선 아래에는 접기만 둔다.
    햄버거 버튼을 상단바에 두지 않는다 — 접기는 여기가 담당.
- **상단바** — 사이드바 우측 끝 ~ 페이지 우측 끝. 좌측 브레드크럼,
  우측 **시계(타임존)·알림**만. 아바타는 두지 않는다(사이드바 하단이 담당).
- **본문** — 상단바 아래 전폭(`p-8`), 페이지 제목 `text-2xl font-bold`
  + 우측 주요 액션 버튼(페이지당 primary 1개). 사용자가 준 화면이 이 영역에 들어간다.

## 본문 관례 — `body-patterns.md` 참조
본문 구성 선례(A 리스트 · B 상세 · C 위저드)는 `layout/body-patterns.md`에 있다.
공통 철칙 하나만 여기서도 강조한다: **고정 요소(하단 바 포함)는 본문 컬럼 안에서만** —
좌측 경계는 사이드바 우측 끝이다. 사이드바를 덮는 전폭 고정(`inset-x-0`) 금지.

## 언제 안 쓴다
- 인증·랜딩·문서형 페이지, 외부 공유용 단독 뷰(리포트 출력 등)
  → **단독 화면**(레이아웃 없음, 중앙 정렬 카드 또는 프로즈 폭)
